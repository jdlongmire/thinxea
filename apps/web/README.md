# ThinxEA web app

Vite + React + TypeScript. Renders the ThinxEA read model
(`public/data/model.json`, generated by `tools/export_read_model.py`)
and talks to the API in `apps/api` for auth and AI features.

    npm install
    npm run dev     # local dev
    npm run build   # production build into dist/

Routes: `/` landing (public); `/dashboard`, `/catalog`,
`/artifact/:id`, `/views`, `/views/:id`, `/standards`, `/roadmap`,
`/evidence`, `/ask`, `/impact/:id`, `/agents` (issued account
required); `/login`, `/request-access`.
